# ITE 1 Individual Portfolio Project

A beginner-friendly, single-page portfolio website for Tinaan, Martin (BSIT 1209). Built with HTML, external CSS, and external JavaScript.

## Files
- `index.html` — website content and sections
- `style.css` — colors, layout, responsive design, and hover effects
- `script.js` — welcome toast, dark/light mode, read more, mobile menu, active navigation, and contact-form demo

## Before submitting
1. Replace the sample project cards with your actual activities from prelim to final.
2. Add your real email address and phone number, if your teacher requires them.
3. Replace the initials profile graphic with your own profile photo if required. To do that, put a photo in the project folder (for example `images/profile.jpg`) and replace the profile-placeholder block in `index.html` with an `<img>` element. Add appropriate CSS for the image.
4. Adjust skill indicators so they honestly represent your current skill level.
5. Test the navigation, theme toggle, read-more button, and contact-form demo.

## Run locally
Open `index.html` in a web browser. For a better coding workflow, open the folder in VS Code and use the Live Server extension if available.

## Deploy using GitHub Pages
1. Sign in to GitHub and create a new repository, for example `ite1-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository's root folder. Keep the filenames exactly as shown.
3. Open the repository's **Settings**.
4. Choose **Pages** from the left menu.
5. Under **Build and deployment**, set the source to **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then click **Save**.
7. Wait a little for GitHub Pages to publish. The website URL will look like `https://YOUR-USERNAME.github.io/ite1-portfolio/`.
8. Open the published URL and test it on your phone. Submit that URL using the link provided by your teacher.

## Important notes
- This is a static portfolio. The contact form only shows a confirmation message; it does not email or store submissions.
- Use only images you have permission to use.
- Do not publish private information you do not want visible to everyone.
